
# Arts For Ecology — assets/ folder

This folder sits next to `index.html` and holds all artwork images.

## Folder structure

```
arts-for-ecology/
├── index.html
├── assets/
│   ├── README.md
│   ├── artwork-001.jpg     ← Lot 001 (Veld in Transition)
│   ├── artwork-002.jpg     ← Lot 002 (Ocean Plastic No. 7)
│   ├── artwork-003.jpg     ← Lot 003 (Smoke Season I–III)
│   ├── artwork-004.jpg     ← Lot 004 (Root Systems)
│   ├── artwork-005.jpg     ← Lot 005 (Carbon Bloom)
│   ├── artwork-006.jpg     ← Lot 006 (Last Wetland)
│   ├── artwork-007.jpg     ← Lot 007 (Rewilding Study II)
│   └── artwork-008.jpg     ← Lot 008 (Nile to Orange)
└── docs/
    ├── PAYMENT_GUIDE.md
    ├── FORM_DATA_GUIDE.md
    └── DEPLOYMENT_GUIDE.md
```

## Artwork image specs

| Property  | Recommendation |
|-----------|---------------|
| Ratio     | 3:4 portrait (800 × 1067 px) |
| Format    | JPEG preferred; PNG or WEBP also work |
| File size | Under 500 KB — compress at tinyjpeg.com |
| Naming    | artwork-001.jpg, artwork-002.jpg ... |

## Attaching an image to a lot

1. Add the file to this folder
2. Go to /#/admin → Artworks → Edit lot
3. Image Path field: `assets/artwork-001.jpg`
4. Save → Export JSON → paste into index.html STORE → re-upload

## No image set?

A decorative green placeholder appears automatically. No broken images.
